# ModulUS — система учёта модульных работ студентов

Веб-приложение для преподавателей и студентов: электронный журнал баллов по
предметам с настраиваемыми столбцами, общением и уведомлениями.

> ⚠️ Сейчас в репозитории — **фронтенд-прототип** (статический HTML + Bootstrap 5
> CDN + тестовые данные-заглушки в `assets/js/app.js`). Бэкенд на Laravel — в планах.

## Возможности

- 🏠 **Лендинг** с описанием преимуществ и блоком «как это работает».
- 🔐 **Регистрация и вход** с выбором роли (преподаватель / студент).
- 👩‍🏫 **Кабинет преподавателя:**
  - CRUD групп, фильтрация по предмету / уровню / поиску.
  - Парсинг названия группы вида `ПИм-231` (специальность + `б`/`м` + год + номер).
  - Журнал оценок: обязательные столбцы **1 / 2 / 3 модуль** и **Итог** +
    неограниченное число промежуточных столбцов между ними (числовых и текстовых).
  - Гибкая настройка суммирования столбцов в модули и итог.
  - Импорт / экспорт журнала в Excel.
  - 3 способа добавить студентов: вручную, по ссылке-приглашению, импорт из Excel.
  - Комментарии к оценкам (диалог преподаватель ↔ студент).
- 🎓 **Кабинет студента:**
  - Мои предметы и сводные баллы.
  - Просмотр оценок и ответ на комментарии преподавателя.
- 🔔 **Уведомления:** студенту — о новых баллах, преподавателю — о вступлении
  студентов в группу по ссылке.

## Структура

```
index.html              лендинг
login.html / register.html   авторизация с выбором роли
teacher-dashboard.html       кабинет преподавателя
groups.html, group-form.html, group-members.html   группы + студенты
gradebook.html               журнал оценок
subjects.html                предметы преподавателя
student-dashboard.html       кабинет студента
student-subjects.html, student-subject.html, student-grades.html
notifications.html           уведомления
assets/css/style.css         стили
assets/js/app.js             тестовые данные и хелперы (заглушки)
```

## Запуск прототипа

Любой статический сервер, например:

```bash
php -S localhost:8765
# затем открыть http://localhost:8765/index.html
```

## Стек (план)

- Фронтенд: Bootstrap 5 (CDN), собственный CSS, ванильный JS.
- Бэкенд: Laravel (запланирован).
